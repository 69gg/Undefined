# memory 工具集

长期记忆相关工具集合，工具名以 `memory.*` 命名。

主要能力：
- 添加/删除/更新记忆
- 列出记忆条目

同一运行时中的增删改与清空共用串行提交锁，先原子落盘再发布内存状态，重复内容只从已提交记录中去重。磁盘写入失败会向调用方报告失败，原有记录和容量淘汰状态保持不变；故障修复后可以重试。Runtime API 的持久化失败返回 HTTP 500，不会返回“已保存”。

普通工具入口由统一注册表将异常转换为“执行 memory.<操作> 时出错: <原因>”，同时记录错误日志及失败统计；各 handler 不重复捕获。自动化使用的 strict 入口保留异常，让工作流能正确判定失败。

等待提交锁时取消会中止尚未开始的变更；实际写入开始后，取消会等待该次写入和内存状态提交完成，再释放锁并传播。列出记忆返回独立记录副本，不能绕过持久化流程修改存储。

目录结构：
- 每个子目录对应一个工具（`config.json` + `handler.py`）
