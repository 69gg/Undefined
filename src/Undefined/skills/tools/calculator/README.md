# calculator 工具

安全的多功能数学计算器。支持算术运算、科学函数、统计函数和常量。输入数学表达式即可计算。

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `expression` | `string` | 是 | 数学表达式，例如：'2+3*4'、'sqrt(144)'、'sin(pi/6)'、'log(1000,10)'、'mean(1,2,3,4,5)'、'2**10'、'factorial(10)'、'gcd(48,18)' |

目录结构：
- `config.json`：工具定义
- `handler.py`：执行逻辑
