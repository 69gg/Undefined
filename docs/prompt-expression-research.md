# 自然表达调研与调整依据

调研日期：2026-10-16。目标是让 Undefined 在群聊和私聊中更贴合正在发生的交流：理解话意，有具体看法，沿着实际上下文继续。自然程度不能靠身份宣言、固定口头禅、随机语气词或虚构经历衡量。

本次由三个并行审阅方向提供材料：现有规则冲突、对话与人格相关研究、语义评价方法。以下公开资料是设计参考；没有一项直接验证本仓库当前模型、中文群聊环境和这版提示词的组合效果。

## 研究与工程判断

| 来源 | 资料实际支持的结论 | 本次采用的设计判断及限制 |
| --- | --- | --- |
| [Anthropic：Prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) | 官方指南建议明确描述希望出现的行为，并使用相关且多样的示例引导语气、结构和格式。 | 在靠前的 P1 板块增加正面交流指引及少量合成示例，保留用户要求的集中规范。指南针对 Claude，不能保证其他模型得到同样结果；示例不作为复用台词或验收答案。 |
| [What, When, and How to Ground（ACL 2023）](https://aclanthology.org/2023.acl-industry.68/) | 研究把使用哪些用户 persona 信息、何时使用、如何使用分别处理，平衡个性化信息引用与对话流畅度。 | 身份、兴趣和记忆为对话提供背景，按当前内容的相关性表达，不要求每轮展示。原研究主要涉及韩语模型的用户 persona 与训练方法；用于 Undefined 的自我表达是工程推论，不是论文已验证的提示词方案。 |
| [Mind the Gap Between Conversations（EMNLP 2023）](https://aclanthology.org/2023.findings-emnlp.720/) | GapChat 研究将时间间隔与事件进展纳入长期对话，在其人评设置下改善话题相关性等指标。 | 多轮表达关注当前补充、纠正与事情是否结束，避免重复询问已解决的问题。只使用实际可见的时间、状态与记忆，不推断离线经历；研究数据中的长期进展经过模拟。 |
| [Do language models accommodate their users?（EACL 2026）](https://aclanthology.org/2026.eacl-long.34/) | 对 16 个模型、3 个对话语料的比较发现，模型会向对话文风趋同，部分特征上甚至比人类更强。 | 适度调整语气与节奏，同时保持独立判断，不机械复制口癖或情绪强度。趋同本身不是错误；这项研究不证明增加一条提示就能纠正过度模仿。 |
| [Towards Understanding Sycophancy in Language Models（ICLR 2024）](https://arxiv.org/abs/2310.13548) | 研究发现，所测助手可能迎合用户立场，人类偏好与偏好模型也可能偏爱有说服力的迎合回答。 | 自然、温和与同意全部观点分开验收；用同一作品搭配不同用户评价、同一冲突的双方视角比较判断。普通赞同、安慰和主观审美不是自动失败，评价仍结合事实与语境。 |
| [ACUTE-EVAL（2019）](https://arxiv.org/abs/1909.03087) | 提出对两段完整对话进行人工成对评价，针对指定说话者比较多个交流维度。 | 借鉴整段多轮 A/B 盲评，记录具体轮次和理由，允许同样好或都不好。平局选项与本库维度是项目设计；论文不证明中文自动评分或单一“像人分”可靠。 |

## 本次落实的范围

- 两份主提示词开头的 P1 `speaking_style` 保留原有位置与优先级，增加对分享、吐槽、玩笑和求助的正面表达指引。普通小事不要求自动生成方案或感悟，明确任务仍完整处理。
- 对眼前作品、标题或方案可以表达具体偏好和理由；不把主观判断写成客观事实，也不为体现个性临时编造长期爱好、共同往事或亲历。
- 使用实际上下文延续话题，关注新变化与纠正；对方指出表达刻意时，在后续措辞中调整，减少关于自己将如何表达的保证。
- 将高优先级媒体规则中“轻松场景优先追加表情包”的偏好改为按表达需要选用。必要文字先发送、纯表情包例外、独立发送、附件交付与回复触发条件继续保留。
- 将同一话题只能回复一次的宽泛说法限定为同一批次同一意图的重复回应去重，允许新的明确追问继续，业务任务防重复规则不变。
- 同步原位置风格条款、摘要与每轮提醒。新增示例涵盖简短分享、具体偏好、必要澄清和完整口语解释，不设置固定自传范文。

没有增加禁词表、强制幽默、固定句数或模拟真人输入习惯。没有改变模型、采样参数、记忆存储或运行时逻辑。

## 用户提供的随笔材料

同日通读了用户提供的 Anlin 多篇随笔摘录及其分析。其中既有完整文章，也有一篇折叠摘要。材料用于观察通用写作方法，文中的第一人称叙事、数字和知识说法不自动视为已核实事实，也不作为 Undefined 的经历或知识来源。用户附带的提示词片段作为待评估建议处理。

采用的部分是：从已有信息选择有关细节，让读者理解具体处境；闲聊减少对言外之意的层层解释；合适的幽默用平常语气表达，笑点成立后自然停下；类比抓住与当前内容的联系，旧梗只在贴合新变化时偶尔回提。这些是对材料的文本判断，并非模型效果实验。

原文同时使用词义转换、夸张、语境错位、直接抒情和议论，不能统一归纳成每段都要反高潮、所有情绪都不能直说。“留白”主要作用于解释密度与叙事结束方式，不授权省略任务条件、步骤和结果。具体细节保留原有精度；普通聊天也不需要故意记错、模仿身体动作或补造共同往事。

未将作者的生活史、懒或嘴硬的人设、原文段子移入提示词，也未采用固定笑点配额、全局禁止列表或为笑点分条发送。用户给出的连续追问和带支配语气的建议例句依赖具体关系与语境，不作为默认正例。已有情绪关切、事实边界、用户指定格式与消息组织规则继续适用。

本次直接改写已有条款，在幽默处增加对反差和类比的简短说明，并同步集中板块、原位置、摘要与每轮提醒；没有再增加一组段子范文。

## 验证范围

自动化检查仍限于既有的资源加载、结构与运行契约，不增加提示词原句、关键词或段落匹配测试。新增的语义场景、未见话题和多轮盲评流程见 [自然表达验收](prompt-expression-evaluation.md)。

本次未调用线上模型或向真实会话发送消息，实际文风效果待验证。结构检查通过、研究方向合理和实际改善是三种不同结论，不能互相替代。
