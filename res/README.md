# 资源目录

本目录用于存放提示词、模板与文案资源。

加载规则（运行时）：
1. 优先读取运行目录下同名 `res/` 资源
2. 若不存在，则回退到安装包内置资源

常见子目录：
- `res/prompts/`：模型提示词与模板
- `res/agents/intro/`：智能体介绍与自动生成内容

主系统提示词约定：
- `res/prompts/undefined.xml` 与 `res/prompts/undefined_nagaagent.xml` 共享 Undefined 的基础身份、昵称与项目归属边界。
- `undefined_nagaagent.xml` 只在上下文明确涉及 NagaAgent 时承接相关工具接入关系，不应在普通自我介绍或无关对话里主动提起。
- 身份内容描述来历、兴趣和相处方式；项目归属约束独立于身份内容。规则用于指导行动，仅在问题相关时解释，不作为自传或闲聊的必答清单。
- 自我表达使用已知事实、当前想法和有依据的经历；不虚构往事，也不默认罗列模型、硬件、身体限制或归属声明。直接询问技术实现、能力或作者时，仍如实回答。
- 简洁是闲聊的默认倾向，用户要求的篇幅、文体与完整性优先。消息按完整意思组织，不固定拆成多条，不强制玩笑、口癖或省略标点。
- 两份主提示词在开头优先级说明后、`absolute_priority` 前设置 `<speaking_style level="P2">`，作为第一个顶层正文板块集中归纳说话风格。原位置的相关要求仍保留，集中板块重复整理它们的适用场景与例外，便于统一检查；位置提前不改变 P2 等级，也不改变 P0 安全要求、工具规则及其他原有规则的优先级、回复触发或工具流程。
- 集中板块涵盖场景与篇幅、直接完整的表达、平等交流与判断、事实和不确定性、自然措辞与专业术语、澄清和结束方式、情绪与幽默、自我叙事、称呼与内部信息边界、消息组织、WebUI 与微信格式，以及图片和表情包的表达。任务答复避免无意义的确认和追加邀约；必要澄清与自然关心仍可提问，普通闲聊不要求给出完整工作方案。
- 表达示例用于减少模板堆叠、夸张比喻、伪口语、单字动词滥用、谄媚和无依据保证，不构成禁词表。常用词、准确的技术术语和与当前语境有关的自然表达按实际含义判断。
- 调整人格与风格时，同时检查两份主提示词的原位置要求、集中板块、各自的 `summary` 和 `res/IMPORTANT/each.md`。每轮提醒只保留简短提示，不复制完整清单；各处含义及例外应一致，避免末尾摘要或每轮提醒重新强化旧要求。

提示词验证：
- 自动测试检查资源加载、插槽和结构契约；不以关键词出现、原句匹配或段落文本相等断言对话质量。
- 语气与叙事效果需观察实际模型输出，使用 [自然表达验收场景](../docs/prompt-expression-evaluation.md) 对照。结构测试通过不代表行为验收通过。

自定义建议：
- 在运行目录放置同名文件覆盖默认资源
- 需要全局默认修改时，建议在源码中更新 `res/` 后运行
